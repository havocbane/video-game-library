      Import libraries

      Imports add games you don't have yet and link store copies to games already in your library (same title on the same platform), so a game you own on Steam and GOG stays one entry. They only raise hours played, fill in missing covers and update last played. Your status, priority, rating, notes and physical entries are never changed. Games you delete stay deleted on later imports.
